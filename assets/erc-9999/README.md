# AIFP assets index

Reference material for the Agent Information Flow Paradigm.

| Path | Contents |
| --- | --- |
| `contracts/interfaces/` | `IAIFPParadigmRegistry`, `IAIFPChannelRegistry`, `IAIFPParticipationRegistry`, `IAIFPPredicateVerifier` (with `IAIFPCompositeVerifier` and `IAIFPSubjectSet`), `IAIFPEventAnchor`, `IERC165`, `IERC6372` |
| `contracts/libraries/` | `AIFPRoles`, `AIFPOutcomes`, `AIFPSubject`, `AIFPPredicates`, `AIFPBindings`, `AIFPBasis`, `AIFPEvents` |
| `contracts/` | reference registries `AIFPParadigmRegistry`, `AIFPChannelRegistry`, `AIFPParticipationRegistry`, the `AIFPCompositeVerifier`, the `AIFPSubjectSet` roster, the optional `AIFPEventAnchor` profile |
| `contracts/companions/` | `AIFPObjectionWindow` (absence semantics companion, not part of the kernel) |
| `schemas/` | `paradigm-descriptor.schema.json`, `predicate.schema.json`, `binding-capabilities.schema.json`, `subject-ref.schema.json` |
| `examples/paradigms/` | one descriptor per named paradigm: source, intake, direct, panel, club, meeting, archive, blackboard, dispatch, forward, derive |
| `examples/composites/` | sealed-bid tender, blind review, embargoed announcement, FOGA handshake, heartbeat liveness, staked agora |
| `examples/invalid/` | descriptors that the canonical validator rejects, one per failure class |
| `vectors/` | `subject-refs.json`, `predicate-encoding.json`, `outcome-tables.json`, `interface-ids.json`, `paradigm-ids.json` |

The canonical validator (`tools/descriptor-validate.mjs` in the repository that hosts these assets) checks a descriptor against the schemas and the identification conditions, derives the per-role predicate encodings and prints the registration bundle for `registerParadigm`. The vectors are regenerated by `tools/make-vectors.mjs` and checked against the contracts by the Foundry suite.
