# Screenshots

Screenshots of a live deployment, to be captured on the current test network season. Screenshots from earlier builds are intentionally not included, because they no longer match the authorization flow described in the [deployment notes](../implementation-notes.md).

| File | Shows |
| --- | --- |
| `apple-front.png` | Apple Wallet pass front: header fields, live countdown from a relative date field, and status. |
| `apple-back.png` | Apple Wallet pass back: the state-changing action links, token id, contract, and network. |
| `google-front.png` | Google Wallet pass front, from the Google-approved loyalty class. |
| `google-details.png` | Google Wallet pass details: the tappable links in `linksModuleData`. |
| `apple-lockscreen-update.png` | An iOS lock-screen notification produced by a push update after on-chain state changed. |

Capture guidance: PNG, device frame optional, no personal information (email addresses, device names, notification content from other apps) visible. Crop to the pass or notification.
